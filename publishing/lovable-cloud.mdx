Lovable Cloud is the built-in infrastructure layer that gives every Lovable app a complete, production-grade backend with zero setup. When you build an app on Lovable, you don't need to configure a cloud provider, provision a database, set up authentication, or write deployment scripts. Lovable Cloud handles all of it automatically — so you can focus entirely on building the product your users need.

## What's Included

Lovable Cloud provisions four core infrastructure components the moment your app needs them. Just describe what you want ("Add user login" or "Save form submissions to a database") and Lovable sets everything up automatically.

## Hosting Infrastructure

Your Lovable app's frontend and backend functions run on **Cloudflare Workers** — a globally distributed edge computing platform that serves your app from data centers close to your users. This means:

- **Low latency** — requests are handled at the edge, not routed through a single origin
- **Global availability** — your app is accessible worldwide without additional configuration
- **Automatic scaling** — Cloudflare Workers scale with your traffic; you don't need to worry about capacity planning
- **DDoS protection** — Cloudflare's network absorbs and mitigates attack traffic automatically

## How to Enable Lovable Cloud Features

You don't manually configure Lovable Cloud — just describe the features you want and Lovable provisions the necessary infrastructure automatically.

Some examples of prompts that trigger Lovable Cloud provisioning:

```
Add user login with Google and email/password
```
```
Save form submissions to a database and show them in an admin table
```
```
Let users upload profile photos
```
```
Send a welcome email when someone signs up
```

Each of these prompts causes Lovable to set up the appropriate Lovable Cloud services — authentication, database tables, storage buckets, or serverless functions — in the background.

## Data Residency

Lovable Cloud supports regional data hosting to help you meet compliance and data sovereignty requirements. You can choose to store your app's data in:

- 🇪🇺 **European Union (EU)**
- 🇺🇸 **United States (US)**
- 🇦🇺 **Australia (AU)**

Customer data stays within your chosen region and does not move across regions by default. Region selection is available in your workspace settings. If you have specific data residency requirements, contact [enterprise support](https://lovable.dev/for-work) to discuss your options.

## Credit Usage for Hosting

For most apps — especially new and small projects — the cost of hosting is fully covered by the **Cloud credit grant** included in your subscription plan.

- **Free plan** includes a monthly grant of 20 Cloud credits
- **Pro and Business** subscriptions include additional monthly Cloud credit grants on top of their general credit balance

Apps that reach significant visitor traffic or size may consume Cloud credits beyond the included grant, which is drawn from your credit balance. You can monitor your Cloud usage in **Workspace Settings → Usage**.

<Note>
  You own your data. Lovable does not keep shadow copies of your database or files, and your data is not used to train AI models on Business and Enterprise plans. You can also connect your own existing Supabase project instead of using Lovable Cloud if you prefer to manage your own database infrastructure — see [Integrate with Supabase](/integrations/supabase) for details.
</Note>

## Using Your Own Supabase Project

If your team already manages a Supabase project, you can connect it directly to Lovable instead of using a Lovable Cloud-provisioned database. This gives you full control over your database infrastructure while still benefiting from Lovable's AI-powered development experience.

See [Integrate with Supabase](/integrations/supabase) for step-by-step instructions on connecting an existing Supabase project.

## Deploying Outside Lovable Cloud

If your organization requires deployment to your own cloud infrastructure (AWS, GCP, Azure, Vercel, Netlify, or another provider), Lovable supports exporting your code and deploying it externally. Because Lovable apps are built on standard React, Tailwind CSS, and Supabase, they work with any hosting provider that supports modern Node.js applications.

See [Deploying Outside Lovable Cloud](/workspace/overview) for a step-by-step guide to external deployment options.

## Security and Compliance

Lovable Cloud is built on enterprise-grade infrastructure with multiple layers of protection:

- **Encrypted storage** — all data at rest is encrypted
- **WAF protection** — web application firewall controls block common attack vectors
- **Network isolation** — workspaces and projects are logically separated at the infrastructure level
- **Automatic security scanning** — every publish triggers a security scan covering database configs, RLS policies, and known misconfiguration patterns
- **SOC 2 Type II** and **ISO 27001** certified

For a full overview of security controls and compliance certifications, see [Workspace Security](/workspace/security).
