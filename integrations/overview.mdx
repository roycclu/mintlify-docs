Lovable doesn't live in a silo. From the moment you start building, you can connect your app to the tools and services your team already relies on — your database, payment processor, CRM, analytics platform, communication tools, and more. Every integration is designed so you spend time describing what you want to build, not wiring up APIs by hand.

## How connectors work

Connectors are OAuth-based integrations. When you (or a user of your app) connects an account, Lovable's gateway handles the full OAuth handshake, stores tokens securely, and refreshes them automatically. Your API credentials never appear in your app's source code or client bundle.

Connections are **per-user**: each person who signs in to your app connects their own accounts — their Google Drive, their CRM records, their calendar. Lovable's gateway manages OAuth, token refresh, and revocation for every user independently.

Connectors also work **offline**. Scheduled syncs and background jobs keep running even when no one is actively using the app, so you can build agents that check for new orders, flag anomalies, or send notifications around the clock.

<Tip>
  Connectors don't cost credits. Credits are only consumed when Lovable generates or modifies your app's code.
</Tip>

## Custom integrations with MCP

If a tool you need isn't in the connector catalog, you can connect it yourself using the **Model Context Protocol (MCP)**. Any tool with a public MCP server can be wired into Lovable in a few steps — no custom code required. See the [MCP Servers guide](/integrations/mcp-server) for details.

<Note>
  New connectors are added every week. If you don't see the tool you need, describe it in the Lovable chat — Lovable can often work with a service's REST API directly, or suggest the best connector to use.
</Note>
