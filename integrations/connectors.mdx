Connectors are pre-built integrations that let your Lovable app exchange data with the tools your users and team already rely on. Lovable handles every part of the authentication and security layer — OAuth handshakes, token storage, token refresh, and revocation — so your API credentials never appear in your app code or client bundle.

<Note>
  Connectors don't cost credits. Credits are only used when Lovable generates or modifies your app's code. Connecting to tools is always free.
</Note>

## Add a connector

<Steps>
  <Step title="Open your project in Lovable">
    Navigate to the project you want to add a connector to from your Lovable dashboard.
  </Step>
  <Step title="Open the Connectors panel">
    Click the **Connectors** button in the project toolbar. You can also describe what you want in chat: *"Connect this to my Google Sheet"* or *"Add a Slack notification when a new user signs up"* — Lovable will open the right connector for you.
  </Step>
  <Step title="Select the tool">
    Browse the connector catalog and click the tool you want to connect. Use the search bar to find it quickly.
  </Step>
  <Step title="Authenticate with OAuth">
    Click **Connect** and complete the OAuth flow for the service. Your credentials are stored securely in Lovable's gateway — they are never written into your app's code.
  </Step>
  <Step title="Describe how you want to use it">
    Back in the Lovable chat, tell Lovable what you want to build. For example:
    - *"Show my last 10 Gmail messages in a list"*
    - *"Post a Slack message to #alerts when an order is placed"*
    - *"Read data from the 'Inventory' sheet and display it in a table"*

    Lovable generates the code that reads from or writes to the connected service.
  </Step>
</Steps>

## Per-user connections

When you build a multi-user app, each person who signs in connects their own accounts — their Google Drive, their CRM, their calendar. Lovable's gateway handles OAuth, token refresh, and revocation for every user independently.

This means your app can show Alice her Drive files and Bob his Drive files without your code ever handling either person's credentials. The gateway manages all of it.

## Background jobs

Connectors work even when your users are offline. Scheduled syncs and background jobs run continuously, so you can build:

- **Invoice chasers** that check Stripe for overdue payments and send Gmail follow-ups overnight
- **Anomaly detectors** that query Snowflake every hour and post to Slack if a metric breaks its bounds
- **CRM syncs** that pull new HubSpot contacts into your database on a schedule
- **Report generators** that write summaries to Google Docs every morning

Lovable monitors your connections and flags anything that needs attention.

## Custom connections via MCP

If the tool you need isn't in the catalog but has an MCP (Model Context Protocol) server, add it via **Connect it yourself** in the connector panel. See the [MCP Servers guide](/integrations/mcp-server) for details.
