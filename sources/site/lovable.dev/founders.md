## Frequently asked questions

### Will I outgrow Lovable?

No, you will not outgrow Lovable. Start building an MVP and scale to full production. Lovable creates a real database, real backend and real integrations. You always own your code and can connect to GitHub anytime.

### What tools does Lovable connect to?

Lovable connects to all the tools you need to build a real business. Pull your ideas from Notion to build faster, build your app with a backend on Supabase for database and auth, connect your app to Stripe to enable payments, connect to n8n to access over 400+ tool integrations, or connect to Shopify to build an e-commerce business. Your app works with your existing stack from day one. Learn more about our connectors [here](https://lovable.dev/connect).

### Do I need to know how to code?

No, you don't need to know how to code. Build by describing what you want. But if you know code, you can dive into code mode anytime.

### Can I use this for client work?

Yes, many founders and consultants use Lovable to ship client projects. You can fully export your project, which means you can deliver production-ready products that clients can own.

### What if I get stuck?

If you get stuck, Lovable helps you debug, suggests fixes, and keeps you moving. Lovable also has a [community](https://lovable.dev/community) where you'll get support from other founders.

### Can my team take over later?

Yes, team members or developers can collaborate or access the code of your product at any time. We offer GitHub sync from day one, and a modern tech stack (React + Supabase + Tailwind) that any developer can work with.
