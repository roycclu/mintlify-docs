# Reporting security issues

We use HackerOne to manage vulnerability reporting. Please report any security issues through our [HackerOne program](https://hackerone.com/lovable-vdp), or send an email to [vulnerability-disclosure@lovable.dev](mailto:vulnerability-disclosure@lovable.dev) to receive instructions on how to submit your report.

This program is for security vulnerabilities in Lovable's own products and infrastructure. To report abuse, harmful content, or apps built with Lovable that violate our policies, go to [lovable.dev/abuse](https://lovable.dev/abuse). For account, billing, or product help, visit [lovable.dev/support](https://lovable.dev/support).
