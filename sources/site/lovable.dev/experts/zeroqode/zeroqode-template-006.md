## Startup Scout

Startup Scout tracks emerging startups — giving you a single platform for funding rounds, metrics, and alerts. Curate watchlists, filter by domains or stage, and stay ahead of trends.

What's Included

Feed — latest startup events (raises, pivots, news) with filters.

Watchlist — favorites, grouped by stage/industry.

Company Profiles — key metrics, history, team, funding timeline.

Round Details — amounts, round types, valuations.

Filters / Explorer — filter by industry, stage, date.

Search / Discovery — keyword search, similar companies, trending.

Data Refresh / Sync — manual sync.

Responsive UI — polished mobile and desktop layouts.
