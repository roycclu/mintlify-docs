## Multi-AI Chat

Multi-AI Chat lets you chat with multiple AI models in one place, switch models on the fly, and compare answers side-by-side. Attach files, set system prompts, and save reusable workflows for faster research and content creation.

What's Included

Chat Workspace — threaded chats with message actions.

Model Selector — pick per-message model.

Side-by-Side Compare — send one prompt to multiple models and compare outputs.

File Attachments — upload PDFs/CSVs/images for analysis within the chat.

History — organize chats, quick search.

Responsive UI — optimized for desktop and mobile.
