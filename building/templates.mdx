Templates are production-ready starting points built by the Lovable community for the most common app and website types. Instead of starting from a blank project and describing your entire app from scratch, you pick a template that closely matches what you're building — then use prompts, visual editing, and Code Mode to make it your own. Every template is a fully functional Lovable project with real components, routing, and — where applicable — Supabase integration already wired up.

## How to use a template

<Steps>
  <Step title="Browse the template library">
    Go to [lovable.dev/templates](https://lovable.dev/templates) to see the full catalog. You can filter by category (Apps or Websites) and subcategory (SaaS, internal tools, e-commerce, portfolio, and more).
  </Step>
  <Step title="Preview before you commit">
    Click any template card to open a live preview of the template. Interact with it to see the components, navigation, and layouts before deciding.
  </Step>
  <Step title="Use the template">
    Click **Use template** to create a new Lovable project pre-loaded with that template's code. You'll be taken straight into the Lovable editor with the full project ready to customize.
  </Step>
  <Step title="Customize with prompts">
    Describe your changes in the chat — update the branding, add new pages, connect your data, or change the feature set. Lovable modifies the template code while preserving what's already working.
  </Step>
</Steps>

## Templates as a foundation, not a constraint

A template gives you a working starting point — it doesn't limit what you can build. Every template is a standard Lovable project, so you have full access to:

- **Prompts** — describe any change and Agent Mode will apply it to the template's code
- **Visual editing** — click elements to restyle them to match your brand
- **Code Mode** — read and edit source files directly for precise customizations
- **GitHub sync** — push to a repository and hand off to developers at any stage

Templates also support all Lovable integrations. You can connect Supabase to a template that doesn't already have a database, add Stripe payments to any app template, or wire up a connector to pull live data from your existing tools.

<Tip>
  Start with the template that's closest to your final vision and describe what's different — this is almost always faster than starting from a blank project. Even if only 50% of the template matches what you need, you save the time of building that 50% from scratch.
</Tip>
