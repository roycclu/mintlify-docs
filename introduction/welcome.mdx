Whether you're a founder validating an idea, a designer bringing mockups to life, a marketer launching a campaign site, or an enterprise team shipping internal tools — you don't need to write a single line of code to get started. You chat, Lovable builds, and your app goes live.

- **Founders & solopreneurs** — go from idea to live product in days without hiring a dev team
- **Product managers & designers** — build interactive prototypes connected to real data, not static mockups

## The Lovable platform

Every app you build with Lovable runs on a modern, production-grade stack — the same technologies used by professional engineering teams.

| Layer | Technology |
|---|---|
| Frontend | React + Tailwind CSS |
| Backend & database | Supabase (PostgreSQL + Auth + File Storage) |
| Hosting | Lovable Cloud on Cloudflare Workers |
| Version control | GitHub (synced from day one) |
| Runtime for new apps | TanStack Start |

## Three ways to build

Lovable gives you three distinct building modes so you can work the way that fits your task:

- **Agent Mode** — describe your goal and let Lovable build autonomously, making decisions and writing code on your behalf
- **Plan Mode** — brainstorm and map out your app's structure before committing any changes, great for complex features
- **Code Mode** — view and edit the generated code directly for precise, surgical changes

You can also use **visual editing** to tweak layouts, colors, typography, and spacing directly on the canvas — no prompting needed.
